# Custom PHP MVC Framework & Environment Documentation

A modern, high-performance, and secure custom PHP MVC application architecture engineered to match 2026 industry-standard engineering guidelines. This platform implements a fully containerized environment separating Public Frontend and Secure Backend (Admin) domain contexts while keeping business logic and data layer access central and unified.

## 🏷️ 2. Core PSR-4 Namespace Standards

To support automatic class detection across the architecture, headers inside components must conform to this blueprint mapping layout:

| File Path Location | Explicit PHP Namespace Protocol Header |
| :--- | :--- |
| `app/Backend/Controllers/DashboardController.php` | `namespace App\Backend\Controllers;` |
| `app/Frontend/Controllers/HomeController.php` | `namespace App\Frontend\Controllers;` |
| `app/Middleware/CsrfMiddleware.php` | `namespace App\Middleware;` |
| `app/Models/User.php` | `namespace App\Models;` |
| `app/Repositories/UserRepository.php` | `namespace App\Repositories;` |
| `app/Services/UserService.php` | `namespace App\Services;` |
| `core/Application.php` | `namespace Core;` |

## 🐋 3. Core Environment Manifest Optimization File Blocks

### Dockerfile (`docker/php/Dockerfile`)
```dockerfile
FROM php:8.4-apache

# 1. Install minimum required system utilities and drop temporary apt-caches
RUN apt-get update && apt-get install -y --no-install-recommends \
    git \
    unzip \
    zip \
    && docker-php-ext-install pdo pdo_mysql opcache \
    && a2enmod rewrite headers \
    && rm -rf /var/lib/apt/lists/*

# 2. Inject optimal production configuration baselines
RUN mv "$PHP_INI_DIR/php.ini-production" "$PHP_INI_DIR/php.ini"
COPY docker/php/opcache.ini $PHP_INI_DIR/conf.d/opcache.ini

# 3. Pull secure Composer engine
COPY --from=composer:2 /usr/bin/composer /usr/bin/composer

# 4. Bind virtual host settings
COPY docker/apache/vhost.conf /etc/apache2/sites-available/000-default.conf

WORKDIR /var/www/html

# 5. Fix permissions for execution stability
RUN chown -R www-data:www-data /var/www/html
```

### OPcache Profile (`docker/php/opcache.ini`)
```ini
[opcache]
opcache.enable=1
opcache.enable_cli=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=20000
opcache.revalidate_freq=0
opcache.validate_timestamps=1
```

### Docker Compose Orchestrator (`docker-compose.yml`)
```yaml
name: mvc-php-app

services:
  app:
    build:
      context: .
      dockerfile: docker/php/Dockerfile
    ports:
      - "${APP_PORT:-8080}:80"
    volumes:
      - .:/var/www/html
    environment:
      DB_HOST: db
      DB_PORT: 3306
      DB_DATABASE: ${DB_DATABASE:-mvc_app}
      DB_USERNAME: ${DB_USERNAME:-root}
      DB_PASSWORD: ${DB_ROOT_PASSWORD:-secret}
    depends_on:
      db:
        condition: service_healthy

  db:
    image: mysql:8.4
    ports:
      - "3307:3306"
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_ROOT_PASSWORD:-secret}
      MYSQL_DATABASE: ${DB_DATABASE:-mvc_app}
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      timeout: 5s
      retries: 5

  phpmyadmin:
    image: phpmyadmin:latest
    container_name: mvc_phpmyadmin
    restart: always
    ports:
      - "8081:80"
    environment:
      PMA_HOST: db
      PMA_PORT: 3306
    depends_on:
      db:
        condition: service_healthy
```

## 🛠️ 4. Explicit Development Operations Playbook (Git Bash / Command Prompt)

Use this step-by-step checklist to initialize or completely reconstruct your workspace locally:

* Initialize Infrastructure (Cold Boot)
  ```bash
  docker compose up -d
  ```
* Synchronize Active Dependencies
  ```bash
  docker compose exec app composer install
  ```
* Optimize PSR-4 Map Storage Tables
  ```bash
  docker compose exec app composer dump-autoload -o
  ```
* Execute System Database Migrations
  ```bash
  docker compose exec app php database/migrate.php
  ```
* Graceful Environment Shutdown
  ```bash
  docker compose down
  ```
* The "Nuclear" Deployment Reconstruction Reset
  ```bash
  docker compose down --volumes && docker compose up -d --build && docker compose exec app composer install
  ```
